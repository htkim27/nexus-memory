# nexus-memory

NexusSum의 계층적 요약 아이디어를 embodied agent의 장기 기억에 적용해 보는 연구용 실험 저장소.

현재는 연구 방향과 PoC 계획을 정리한 초기 단계입니다. 시뮬레이터, 에이전트, 메모리 모듈은 아직 구현하지 않았으며 실험 결과도 없습니다.

## 연구 배경

[NexusSum](https://arxiv.org/html/2505.24575v1)은 긴 서사 텍스트를 전처리하고 요약한 뒤 계층적으로 압축하는 프레임워크입니다. 이 저장소에서는 그 아이디어를 관찰·행동 이력의 온라인 기억 관리로 확장할 수 있는지 탐색합니다. 온라인 갱신과 행동에 필요한 상태 보존은 이 프로젝트에서 새로 검증할 부분입니다.

[MEM: Multi-Scale Embodied Memory for Vision Language Action Models](https://arxiv.org/abs/2603.03596)은 단기 비디오 기억과 장기 텍스트 기억을 결합하며 최대 15분 길이의 로봇 태스크를 보고합니다. [Physical Intelligence의 설명 글](https://www.pi.website/research/memory)은 같은 연구를 소개합니다.

핵심 질문은 **제한된 컨텍스트 예산 안에서 계층적 요약이 과거 관찰, 완료한 하위 목표, 실패 이력을 보존해 장기 태스크 수행을 개선하는가?** 입니다. MEM보다 나은 성능을 내는지는 검증할 가설이며, 시뮬레이션 결과만으로 실제 로봇에서의 우위를 주장하지 않습니다.

## 초기 PoC 범위

- 실제 로봇 없이 [AI2-THOR](https://github.com/allenai/ai2thor)에서 관찰과 이산 행동을 사용하는 에이전트 루프를 구성합니다.
- [ALFRED](https://github.com/askforalfred/alfred)의 언어 지시 기반 가정 내 태스크로 기본 동작과 평가를 시작합니다.
- 동일한 에이전트에 서로 다른 메모리 전략을 연결해 기억 관리의 효과를 비교합니다. 첫 PoC는 고수준 계획 에이전트를 대상으로 하며, end-to-end VLA 학습은 후속 범위입니다.
- 장기적으로 15분 이상의 복합 태스크를 탐색하되, 표준 ALFRED 평가와 별도로 설계한 장기 시나리오의 결과를 분리합니다.

## 메모리 설계 가설

최근 관찰·행동·결과를 짧은 버퍼에 보관하고, 이전 이력을 하위 태스크별 요약과 에피소드 수준 요약으로 압축합니다. 계획기는 현재 관찰과 이 기억을 함께 사용해 다음 행동을 결정합니다.

요약에 보존할 정보의 후보는 물체의 마지막 관찰 위치와 상태, 완료한 목표, 남은 목표, 실패한 시도, 아직 확인하지 못한 사실입니다. 각 기억에는 원본 이벤트 ID와 관찰 시점을 연결해 상태 변경과 요약 오류를 추적합니다. 이는 구현 전 설계안이며, 압축 주기·계층 수·토큰 예산은 실험으로 결정합니다.

## 비교 및 평가 계획

| 메모리 전략 | 목적 |
| --- | --- |
| 현재 관찰만 사용 | 과거 기억이 없는 기준선 |
| 최근 이력만 유지 | 고정 길이 sliding window 기준선 |
| 단일 누적 요약 | 계층화 자체의 기여 확인 |
| 계층적 요약 | NexusSum에서 착안한 제안 방식 |

모델, 관찰 정보, 행동 공간, 태스크, seed, 최대 행동 수를 고정합니다. 메모리를 사용하는 방식에는 동일한 기억 토큰 상한을 적용하고, 요약을 위한 추가 호출 비용도 별도로 기록합니다.

평가 항목은 태스크 성공률, 목표 조건 달성률, 행동 수, 반복·불필요 행동, 기억 질의 정확도, 컨텍스트 토큰 수, 요약 비용 및 지연시간입니다. 여러 seed와 에피소드에 걸친 결과를 보고합니다.

“15분”은 실행 환경과 추론 지연에 따라 달라집니다. 벽시계 실행시간과 행동 단계 수, 기억을 유지해야 하는 단계 간격을 함께 기록하고, 시뮬레이터가 제공하는 시간 지표가 있다면 별도로 명시합니다. 실행이 느려서 15분이 걸린 것을 장기 기억의 증거로 해석하지 않습니다.
